# Investment-Backtester
Stochastic Portfolio Engine: Built an institutional-grade Monte Carlo forecaster integrating GBM and Stochastic Volatility to model 100 paths over a 2-year horizon. Features multi-asset weights, automated DCA scheduling, Custom Portfolio matrix and Yahoo Finance API 
*Portfolio Matrix: Supports custom multi-asset weight configurations and tracks cross-asset historical correlations.
Capital Injections: Simulates dynamic cash-flow timing to model the exact compounding impact of Dollar-Cost Averaging (DCA).
Data Pipeline: Automated ETL pipeline sourcing split- and dividend-adjusted data from the Yahoo Finance API across 1,250 historical data points.
